# PELAKU SENI DAN BUDAYA — DKD PPU

Paket v2 untuk branch `data-pelaku-seni-budaya`.

## Kategori
- Seniman
- Sanggar
- Komunitas
- Band
- Pelaku Budaya

## Struktur Band
- Nama Band
- Jumlah Personil
- Nama Personil 1, 2, 3, dst. otomatis sesuai jumlah personil
- Genre Musik / Bidang Seni
- Kecamatan
- Desa/Kelurahan
- Tahun Berdiri
- Kontak/WhatsApp
- Instagram/Facebook/YouTube
- Foto Band
- Logo Band
- Deskripsi/Profil

Tidak ada field Nama Vokalis dan tidak ada Link Lagu/Video.

## Instalasi awal
Upload file-file paket ini ke branch `data-pelaku-seni-budaya`.
Untuk sementara uji halaman melalui:
`/pelaku-seni-dan-budaya.html`

## Catatan penting
Paket ini adalah tahap UI + kerangka API. API membutuhkan Cloudflare D1.
Upload foto/logo produksi membutuhkan Cloudflare R2 dan endpoint upload yang aman.
Admin/verifikasi produksi juga perlu autentikasi sebelum dipublikasikan.
